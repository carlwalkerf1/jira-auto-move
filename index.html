Support → Engineering handoff

CSUP Auto-Move: what the tool does

A browser tool that moves a Customer Support ticket into Engineering and fills in the routine fields automatically. Everything below is driven by one field on the source ticket — Primary Engineering Domain Team — and every rule here is editable.

⤷ Auto-Move run from any CSUP issue — the button, or Ctrl + Shift + M

Also done

Reporter → previous assignee

Whoever was assigned becomes the Reporter, then the ticket is unassigned. If the CSUP had no assignee, Reporter falls back to whoever ran Auto-Move.

Original ticket link

Stamps the source CSUP key into the “Original Ticket” field for tracking.

Description copied

The full description is copied into “CSUP ticket” — formatting and images preserved.

PSE comments preserved

PSE-restricted comments are grabbed before the move; afterward you pick which to keep and they’re saved into “PSE Notes.”

The field-fixable cases — a blank, PLT, Infosec, or unlisted team, or a missing required field (Bug / Customer Impact) — don’t move the ticket and also open the PSE tab so you can fix it. All of this text lives in the CONFIG block and is editable.

If something goes wrong — send a report

Auto-Move fails loud: if a step breaks it stops and shows a red panel naming the exact step that failed — it never half-moves a ticket and walks away. Getting that report to Carl takes about ten seconds:

  1. Reproduce it — run Auto-Move on the same ticket so the red panel appears.
  2. Click ✉ Send to Carl — this opens your mail app with a message already addressed to Carl and copies the full diagnostics to your clipboard.
  3. Paste into the email body (the panel confirms “full details copied, paste & send”) and send.

No mail app, or the button didn’t fire? Click ⧉ Copy diagnostics and send the copied text to Carl any way you like — or open the browser console and copy the [FE AutoMove] DIAGNOSTIC SNAPSHOT dump (also available as window.__feAutoMoveSnapshot).

Tip — keep this tab focused while a move runs. Switching to another browser tab mid-move can stall it (browsers throttle background tabs and block focus), and it won’t always show an error. While a move is running the tool shows a reminder; if you did switch away and nothing finished, come back, refresh, and run it again.

What you can change

Every rule on this page lives in one place

All of it is a CONFIG block at the top of the script — no code changes needed to adjust the rules:

  • Add / remove / re-route a team — the ROUTES list (destination + the ENG Team and Domain it maps to)
  • Change a constant value — CONST_FIELDS
  • Change which fields trigger the reminder — REMINDER_FIELDS
  • Turn features on/off — description copy, PSE comments, the post-move refresh
  • Change the keyboard shortcut — HOTKEY

Possible future features

Ideas, not planned work — noted here so the thinking isn’t lost.

Smarter churn handling Possible eventually For Operations churns (label pse_churn), Auto-Move could clone the CSUP first, move the clone to Cloud Operations, and mark the original Done with the pse_close / pse_ops labels — so the churn still counts toward pse_close targets after it leaves the CSUP project. It would also detect a clone you’ve already made (via the “clones” link) so it won’t double-clone.
Dynamic (Signal) CSUP support Long shot Auto-Move only handles the Customer Issue - Firstup type; Customer Issue - Dynamic (the Signal product, which is being retired) isn’t supported. For now the button is simply hidden on Dynamic issues — move and fill them in manually.
Images in PSE Notes Long shot PSE-restricted comments are copied into PSE Notes after the move, but any images embedded in those comments don’t carry over — the text and links come through fine, the images just show “Preview unavailable.” (Description images are unaffected — those are issue attachments, which do move with the issue.) Fixing this means downloading each image and re-uploading it to the new issue, which is more work than it sounds like. If you need the image from a PSE comment, check the original CSUP.
